# Git repo

This extension is in a subdirectory that is gitignored by the SwarmUI project. This extension has its own repo. Do not look in the SwarmUI project for any git changes related to this extension.

# Javascript files

Do NOT manually modify `Assets/whattheduck.js` (or its source map). It is generated by the build. All Javascript modifications should be applied to the TypeScript files in the `frontend` directory (or `scripts`). It is OK to modify the CSS file(s) within this project directly.

The frontend is bundled into a single `Assets/whattheduck.js` file by esbuild.

# Build commands

Run from this extension's root directory (the folder that contains `package.json`):

- `npm install` — install toolchain (biome, esbuild, typescript, jest).
- `npm run check` — format check + lint + typecheck (no output written to Assets).
- `npm run build` — lint, check, then bundle `frontend/main.ts` into `Assets/whattheduck.js`.
- `npm run test` — run the Jest unit-test suite (`frontend/**/*.test.ts`).
- `npm run test:coverage` — run the tests with a coverage report written to `coverage/`.
- `npm run clean` — remove the generated bundle and source map.

Run `npm run test` after any change that touches the `frontend` TypeScript modules.
